# 示教接口说明

当前硬件冻结版本提供关节拖动示教接口，示教期间六个关节和手爪失能，但主控继续通过 CAN 读取编码器反馈。

## 命令

| 命令 | 作用 | 前置条件 |
|---|---|---|
| `!TEACH_ON` | 进入示教，失能关节和手爪 | 设备已启动、无运动任务、反馈新鲜、关节已停止 |
| `#GETJPOS` | 读取当前六轴位置和手爪状态 | 示教期间可用 |
| `#GETLPOS` | 根据当前六轴位置读取末端位姿 | 示教期间可用 |
| `!TEACH_OFF` | 读取当前位置、重新使能并发送当前位置保持点 | 当前处于示教状态 |

## 安全行为

- 示教状态拒绝新的关节、笛卡尔、手爪和调参动作。
- `!PAUSE` 在示教状态下拒绝。
- `!STOP` 仍可触发急停；`!RESUME` 会恢复到示教状态，不会直接进入运动状态。
- 退出示教时如果位置反馈不新鲜、超出关节限位或保持点发送失败，设备保持失能示教状态并返回错误。
- 退出示教成功后，当前位置被同步为运动目标，避免重新使能时跳回进入示教前的目标位置。

## 上位机录制建议

上位机进入示教后以固定周期调用 `#GETJPOS`，保存时间戳、六轴位置和手爪状态。回放前应退出示教、确认 `STATE:NORMAL`、重新读取当前位置并由上位机逐点发送 MoveJ 命令。
