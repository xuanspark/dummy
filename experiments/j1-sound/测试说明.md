# J1 短音可行性与音量实验

**2026-11-18 独立实验版 v1.2.1-exp1**

本轮只判断 J1 电机本体是否能发声、听感音量是否可用。尚未烧录实测，不能把编译通过或电流指令值当作声音、分贝或实测绕组电流。

## 实验边界

仅节点 1 接受实验 CAN 命令。保持原位置闭环与目标，在转子磁轴方向叠加单向带偏置的正弦励磁，使用 5 ms 起止包络，不修改 PWM 载波、20 kHz 控制频率或 PID。

- 频率：400～2000 Hz；时长：50～500 ms。
- 励磁峰值：25～250 mA，且不超过子板额定电流设置的四分之一。
- 闭环转矩优先，额定电流没有余量时缩减励磁；因此相同指令不保证相同音量。
- 本地定时结束，结束或取消后冷却至少 1 秒。没有通信也会结束。
- 开始时要求已使能、已 HOME、队列为空且处于静止位置模式；不会自动使能或归位。
- 偏离开始时的编码器位置超过 128 子步、失能、制动、校准、故障或切换运动模式会取消短音。128 子步约等于电机轴 0.9°，按 J1 的 50 倍减速比约为关节 0.018°，属于软件检测阈值，不代表实测位移精度。
- STOP 沿原最高优先级速度零路径下发；子板收到速度零命令先取消发声，再执行停止。RESUME 不重播实验短音。
- 本轮不是音频播放或正式声音通知功能，不把音量档位、旋律、UI 或业务状态联动并入原固件。

## 命令

```text
#STATUS
#J1_SOUND
!J1_SOUND 1000 200 50
!STOP
```

`!J1_SOUND` 的参数依次为 Hz、ms、励磁峰值 mA。`Accepted` 表示子板已经受理，随后 `OK SOUND:2` 表示本地短音正常结束；错误或取消不会报告正常完成。

查询回包 `SOUND`：0 未播放，1 播放中，2 正常结束，3 已取消，4 条件变化或位置偏移导致中止。

启动失败 `CODE`：1 参数或额定电流限制不符，2 已在播放，3 冷却中，4 未满足静止位置保持条件。`no_experiment_ack` 表示未收到本次实验子板协议确认，不能继续试音。

## 烧录后的测试次序

1. 先只读核对 REF 版本 `1.2.1-exp1`、子板 `EXP:1`、在线状态和角度。
2. 在机械臂周围已清场的条件下，按原流程完成 START、HOME；脚本不会代做这些运动。
3. 从 1000 Hz、200 ms、50 mA 单次短音开始。每次记录听感和有无可见位移、抖动、异常；确认后再逐步试 100、150、200、250 mA，不自动连播提升强度。
4. 若首个频率不明显，在同一较低强度下分别比较 400、800、1000、1600、2000 Hz。每次间隔至少 1 秒。
5. 选定可听到的低强度，执行 500 ms 短音，并在受理后约 100 ms 发送 STOP，检查取消状态和使能保持；恢复只清除急停，不自动重播。
6. 记录测试前后角度；这些读数不能替代播放期间位移或抖动的现场观察。

使用现有 Python 环境和 pyserial，无需更改上位机：

```powershell
E:\Python\313\python.exe experiments\j1-sound\probe.py --port COM3
E:\Python\313\python.exe experiments\j1-sound\probe.py --port COM3 --play --frequency 1000 --duration 200 --amplitude 50
E:\Python\313\python.exe experiments\j1-sound\probe.py --port COM3 --play --frequency 1000 --duration 500 --amplitude 50 --stop-after 100
```

执行前关闭占用同一串口的软件。脚本不会主动关闭 GUI、清除串口缓存或复位控制板；Ctrl+C 会尝试发送 STOP。

没有经校准的声级计时，听感记录使用“听不到、轻微、清晰、较响”，同时记录观察距离、背景噪声、频率、时长、强度与位置变化。手机读数只能标为参考，不能作为校准分贝值。
