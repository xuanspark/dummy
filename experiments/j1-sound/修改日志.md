# 发声实验修改日志

## **2026-11-18 增加单 J1 专项测试模式（v1.3.1-exp2）**

- 用户确认只保留 J1 接线，允许专项固件跳过整臂前置限制。新增 `!J1_TEST_START`，只使能节点 1，直接以子板本地编码器当前位置作为保持目标，不要求其他节点在线，不执行整臂 START 或 HOME。
- 单节点模式独立报告 `MODE:J1_ONLY HOLD:1 READY:1`，不伪造整臂使能或 HOME 标记；重复准备保持原目标，实验子板开机等待显式准备，不采用 EEPROM 自动使能选项。
- REF 与 J1 子板锁存专项隔离，拦截普通运动和参数写入；查询和 RGB 不受此隔离影响。限流、限时、冷却和 STOP 取消继续保留，恢复不重播短音。
- 修正单节点急停路径：整臂标记未使能时也能向节点 1 下发取消；保持位置闭环，不广播、不切换速度模式。准备期间的急停也不能返回准备成功。
- 升级实验协议为 `EXP:2`；旧子板不能进入单节点模式。Python 脚本增加 `--j1-only` 与显式 `--prepare`，默认仍为只读。
- 补充真实控制器、主控调度及串口替身验证；新固件归档为 `ref11180023_TEST-J1-SOUND`、`42motor11180023_TEST-J1-SOUND`，旧构建保留。新版尚未烧录实测。
- 三组固件离线检查和 9 项 Python 替身检查通过，两份 Release 编译、启动向量与归档校验通过；REF 静态 RAM 127528 字节，42 静态 RAM 7776 字节。原正式源码未改动。
- 补录旧版两次实机试音：1000 Hz / 200 ms / 50 mA 及 1000 Hz / 300 ms / 100 mA 均正常回包，但现场均未听到，不能判定发声或音量测试通过。
