# 控制升级任务清单

日期：2026-11-17。基线提交：053fe1b。功能版本：上位机 0.2.0，主控 1.1.0。

## 已确认需求

1. STOP 最高优先级，停止机械臂和手爪，保持使能，保留当前任务及剩余队列；重复 STOP 返回急停状态。
2. PAUSE 在当前指令完成后阻挡下一条指令，保留队列和使能；STOP 可将暂停升级为急停。
3. RESUME 区分急停与暂停，恢复被打断的指令或从下一条继续；重复 RESUME 返回当前状态。
4. 暂停、急停时允许只读查询和恢复；其他业务指令拒绝，响应包含状态。STOP 始终允许，PAUSE 不降级急停。
5. START 使能机械臂及手爪，回零点姿态 REST_POSE；HOME 是另一工作姿态。未使能不得执行运动。
6. 仅运动及手爪动作在尚未 HOME 时先静默 HOME。查询、RGB、参数操作不触发 HOME。
7. CLOSE 完成回零点姿态后才调用内部 DISABLE；停止、暂停、通信异常及回零失败均不得绕过检查失能。
8. 不开放直接失能命令；动作采用单一队列执行，通信接收和 RGB 保持独立。
9. 手爪与机械臂同步使能、失能，动作过程联动自动灯光。
10. OFFSET_J 支持单节点与 all，全部关节写入后自动重启；写入和重启流程可被 STOP 阻断。
11. SETPID 支持单节点全部 KP/KI/KD/KV 和单参数，节点包括手爪。
12. GETPID 支持单节点单参数、单节点全部、全部节点，兼容已有 GET_DCE。
13. 保留 0～11 全部灯效；自动模式为白色呼吸、绿色常亮、青色慢闪后约 5 秒待机、红色渐变快闪、黄色流水。

## 复审修正

- CAN 发送失败不再更新使能标记；STOP 抢占失能过程时重新保持使能。
- 空闲控制环不再重复下发旧目标，维护操作和已排队动作互斥。
- 自动 HOME 属于当前动作的一部分，PAUSE 等其后的实际动作完成才阻挡下一条。
- 手爪电流达到设定值不代表夹持结束，使用新的堵转反馈判定。
- 保留 !HD_ZERO 和 !CALIBRATION，改为可被急停打断、保持使能的队列流程。
- UART 增加独立急停扫描任务和整行输出互斥，修复 UART5 错用 UART4 二进制解析器。
- 发布构建保留 NaN/Inf 校验；异常位置反馈不更新角度序列。
- 前端动作等待不受普通 HTTP 超时限制，补发拖动后的最后目标，停止后清除尚未受理的本地目标。
- 动作排队等待不消耗执行超时，支持受理、开始执行、最终完成三个阶段。
